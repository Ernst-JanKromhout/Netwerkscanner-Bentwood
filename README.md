# Netwerkscanner-Bentwood

Home Assistant-add-on die het thuisnetwerk volgt en meldt wat er verandert.

## Installeren

1. Home Assistant: **Instellingen → Add-ons → Add-on-winkel → ⋮ → Repositories**.
2. Voeg `https://github.com/Ernst-JanKromhout/Netwerkscanner-Bentwood` toe.
3. Installeer **Netwerkscanner**, vul de opties in en start hem.

Zie [netwerkscanner/DOCS.md](netwerkscanner/DOCS.md) voor wat hij doet en hoe je hem instelt.

## Ontwikkelen

```
pip install pytest requests
python -m pytest
```
